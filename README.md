# agent-hub starter — 一人の生活を「AIの部署」で回すキット

## ひとことで言うと

**あなたの生活を、AIの会社組織に任せる仕組みです。**

勉強・仕事・お金・体調・趣味がいっぺんに動く生活を、全部一人で管理するのは大変です。そこで AI（Claude Code）の中に「司令塔」と「専門の部署」を作り、日々のことを分担させます（このキットでは部署のことを「部門」と呼びます）。このキットは、その仕組みをあなたのPCに作るためのものです。

どんな部門を作り、何を任せるかは**あなた次第**です。最初にClaudeが質問をして、あなた専用の構成を組み立てます。

## 場面で言うと

たとえばこう話しかけます。

> 「今月のお金どうなってる？」

返事をするのは司令塔ですが、司令塔は自分で家計簿を開きません。**お金の担当に仕事を回し**、上がってきた報告を確かめてからあなたに返します。

> 「来週の予定と体調を見て、無理のない計画を立てて」

この場合は、予定の担当と体調の担当に同時に仕事が回ります。司令塔は2つの報告をつき合わせて、1つの答えにまとめます。

あなたは「誰に頼むか」を考えなくてかまいません。話しかければ、司令塔が担当を選びます。

## 1. 組織のつくり

### 司令塔（社長室）

- あなたの価値観・優先順位・目標を読み込んで、「もう一人のあなた」として判断します。
- やることは**振り分け・確認・まとめ**の3つだけです。データを直接書き換えたり、担当の仕事を代わりにやったりはしません。だから部門をいくら増やしても、司令塔は重くなりません。

### 専門エージェント（あなたが決める部門）

| 分野 | 部門の例 |
|---|---|
| 生活 | 予定・やること、体調・睡眠、暮らしの知恵、固定費の見直し |
| お金 | 家計簿・収支、税金、持ち物の相場 |
| 仕事 | 案件の進み具合、取引先の条件、メールの作成、仕事探し |
| 学び | 課題や資料の作成、成績、資格の勉強 |
| 趣味・発信 | 練習の記録、SNSの数字の分析 |
| 調べもの | 業界のニュース、進路の調査 |

最初は3〜6部門から始めるのがおすすめです。あとから「◯◯の部門を作りたい」と言えば増やせます。

部門ごとに「どのファイルを読むか」「どの形で報告するか」を書いた指示書（`agents/XX_*/CLAUDE.md`）ができます。

### 仕事の重さで AI の頭脳を変える

| 重さ | 作業の例 | モデル |
|---|---|---|
| 軽い | 記録をつける、集計する | 安くて速いモデル |
| 中くらい | 調べる、分析する | 中くらいのモデル |
| 重い | 提出する文書・メール・納品物など、出来がそのまま評価になる物 | いちばん賢いモデル |

## 2. AI に嘘をつかせないための工夫

このキットの決まりの多くは、**AI がもっともらしい作り話をしないように**するためのものです。

- **「読んだファイル」を必ず書かせる**
  指示が短すぎると、AI はデータを読まないまま、それらしい報告を作ってしまいます。そこで、仕事を頼む文には「まず自分の指示書を読め」という行を必ず入れます。報告の最後には、実際に読んだファイルの一覧を書かせます。一覧がない報告は受け取りません。
- **データが読めなかったら、正直に「作業できない」と言わせる**
  それっぽい数字で穴を埋めさせません。
- **ネットで調べた数字には出典と日付を付ける**
  付いていない数字は報告に使いません。
- **データの正本は1か所だけ**
  「収支はこの表が正」「持ち物はこの一覧だけが正」のように決めます。ほかの資料から推測させません。
- **1つのファイルに書き込むのは1つの担当だけ**
  誰が書いたか分からない記録を作りません。

## 3. 放っておいても回る自動化（どれも任意）

| いつ | 自動でやること |
|---|---|
| 毎朝（時刻は自分で決める） | 全部門が自分の担当を確かめ、**知らせることがある部門だけ**が短く報告する（日次報告） |
| 報告のあと | 全部の報告を1通にまとめて、スマホの LINE に届ける |
| 報告の前 | 前日までの会話を読み返し、**2回直されたことを「覚える」** |

- **ダッシュボード**：エージェントたちが今何をしているかを、ブラウザ（http://localhost:8765）でいつでも見られます。日次報告に「確認した」の印を付けると、同じ件は次の日から出てきません。
- **日次報告は事実まで**：報告は「何が・いつから・どれだけ」を伝えるものです。いつ何をするかは、あなたが決めます。

---

## 4. あなたの好みを「覚えて育てる」

AI は会話が終わると内容を忘れてしまいます。そこで、**直されたことを記録として残し、次から守る**ようにしています。

- **その場で覚える**：「今後はこうして」と言えば、司令塔が記録に残します。
- **あとから拾う**：言い残しは、毎朝のスクリプトが会話を読み返して拾います。一回限りの手直しを決まりにしないよう、別々の会話で2回出たものだけ覚えます。違うと思ったら「12番は覚えなくていい」で取り消せます。
- **好みの台帳**：デザインや文章のように好みが強く出る物は、指摘をためる台帳を部門に持たせて、作る前に必ず読ませます。

## 5. 使い込むと、自分専用の道具まで作れる

このキットの本当の伸びしろは、ここにあります。使っていて「これ毎回面倒だな」と感じたら、そのまま司令塔に言ってください。Claude Code があなた専用の小さな道具を作り、ハブにつなぎます。**プログラムを書ける必要はありません。** あなたは何が面倒かを話すだけです。

| 面倒なこと | 作れる道具 | こうなる |
|---|---|---|
| 通知メールの金額を手で写している | 毎朝の自動読み取り | 請求や入金が、何もしなくても記録に入っている |
| 再生数やフォロワー数を見に行って伝えている | 毎朝の自動取得 | 「今月どうだった？」に、聞き直しなしで答えが返る |
| サイトで開いた資料を毎回保存して整理している | ブラウザの拡張機能 | 開いただけで、決まったフォルダに振り分けられる |
| 気になったページを後で見返せない | ブラウザの拡張機能 | ボタン1つで台帳に入り、次に作るときの参考にされる |
| 練習や勉強の時間をつけ忘れる | メニューバーの小さなアプリ | タイマーを押すだけで記録に入る |
| 出先や寝る前に記録したい | スマホからの受信箱 | スマホで一言メモすると、あとで担当が取り込む |

司令塔は、あなたの話に「面倒」「毎回」「手で」が出てきたら、頼まれたことを済ませたうえで、こうした案を1つだけ添えます。作るかどうかはあなたが決めます。最初から道具の話を並べることはしません。

作った道具は、担当の部門の記録に直接つながります。だから、道具を増やすほど「話す手間」が減り、「頼まれる前に揃っている」状態に近づきます。

---

## 6. 重くしすぎないための工夫

AI には一度に読める文章量の上限があり、読ませた量だけ使用量もかかります。

- 全員が最初に読む起動ファイル（`CLAUDE.md`）は、ごく短い「入口」だけです。本体の指示書は役割ごとに分け、**必要な人が必要なときだけ読む**形にしています。
- ネット検索は1回の依頼で最大4回までにし、検索結果を報告にそのまま貼らせません。
- 毎朝の日次報告は、軽いモデルで・読むだけで回します。

## 必要なもの

- **Mac または Windows**（どちらでも同じように動きます。自動起動の仕組みだけ、OSに応じて自動で切り替わります）
- [Claude Code](https://claude.com/claude-code)（AnthropicのAIエージェント。サブエージェントを多用するので有料プランをおすすめします）。Windowsでは PowerShell またはコマンドプロンプトからそのまま使えます。
- **Python 3**（ダッシュボードと日次報告に使います。この2つを使わないなら不要です）。入っているかどうかは、セットアップ中に Claude が自分で確かめます。
  - Windowsで未インストールの場合は python.org からインストールし、インストーラーで「Add python.exe to PATH」に必ずチェックを入れてください。
  - Macで「コマンドライン・デベロッパツールが必要です」と出たら、そのまま「インストール」を押してください。

## はじめかた（4ステップ）

パソコンに詳しくなくても進められるように書いています。文字を打ち込む黒い画面（ターミナル）を使いますが、打つのは数行だけです。

### 1. Claude Code を入れる

[Claude Code の公式ページ](https://claude.com/claude-code)の案内どおりにインストールします。入れ終わったら、次のステップ3で初めて起動したときにブラウザが開くので、自分の Claude のアカウントでログインします。

### 2. このキットを手に入れる

**いちばん簡単な方法（ZIP）**

1. このページの上のほうにある緑の「Code」ボタンを押し、「Download ZIP」を選びます。
2. ダウンロードした ZIP を開く（解凍する）と、`agent-hub-starter-main` というフォルダができます。
3. そのフォルダを、**消えない場所**に移します。おすすめはホームフォルダ（Macなら「書類」の1つ上、Windowsなら `C:\Users\あなたの名前`）です。iCloud や OneDrive で同期されているフォルダ（デスクトップ・書類など）は避けてください。中身がクラウドにもコピーされます。

**git を使える人**

```bash
git clone https://github.com/im-tanakaTV5/agent-hub-starter.git agent-hub
```

### 3. そのフォルダで Claude Code を起動する

- **Mac**：Finder でフォルダを右クリックし、「フォルダに新規ターミナル」を選びます（メニューに無ければ「サービス」の中にあります）。
- **Windows**：エクスプローラーでフォルダを開き、何もないところを右クリックして「ターミナルで開く」を選びます。（Windows 10 では、Shift キーを押しながら右クリックして「PowerShell ウィンドウをここで開く」）
- **どちらも見つからないとき**：ターミナル（Windowsは PowerShell）を開き、`cd` と半角スペースを打ってから、フォルダを画面の中へドラッグして Enter を押します。

黒い画面が開いたら、次の1語を打って Enter を押します。

```bash
claude
```

### 4. 「セットアップ」と入力する

あとは Claude が質問をしながら、あなた専用の司令塔・部門・記録の置き場所を組み立てます（20〜30分）。

- 質問は1〜2問ずつです。分からない言葉があれば、その場で「◯◯って何ですか？」と聞いてください。
- 決められないことは「おすすめで」と言えば、理由つきで決めてくれます。
- 途中でやめても、次回また「セットアップ」と言えば続きから再開できます。

### 途中で「許可しますか？」と何度も聞かれます

Claude Code は、ファイルを作る前やコマンドを動かす前に、毎回確認を出します。セットアップ中は部門や記録表をまとめて作るので、この確認が何十回か続きます。故障ではありません。

- 出てきた内容を見て、問題なければ「Yes」を選びます。
- 「今後は聞かない」という選択肢を選ぶと、同じ種類の確認は出なくなります。
- このキットのセットアップが触るのは、このフォルダの中だけです。ダッシュボードと毎朝の報告を希望した場合だけ、パソコンの自動起動に登録します。

### 2回目からの始めかた

ステップ3と同じです。フォルダでターミナルを開いて `claude` と打ちます。前の会話の続きから始めたいときは `claude -c` と打ちます。

## セットアップ後の使い方

- **普段**：Claude Code に話しかけるだけです。「今週の予定は？」「◯◯に3,000円使った」。司令塔が担当に振り分けます。
- **返事には少し時間がかかります**：1件の記録でも、担当を呼び出して書き込むので30秒ほどかかります。いくつかまとめて話すと、同時に処理されるので効率的です（「ランチ900円。昨日は1時に寝て7時に起きた」）。
- **記録を見る**：「今月いくら使った？」と聞くのがいちばん簡単です。記録そのものは `shared` フォルダの中に、Excelで開ける表として入っています。直したいときは表を直接書き換えず、「さっきの900円は800円だった」と話してください。
- **毎朝**：日次報告を有効にしていれば、ダッシュボードに各部門の報告が並びます。「今日の報告は？」と聞いても読めます。
- **直す**：出てきたものが違うと思ったら、その場で言ってください。直されたことは覚えて、次から守ります。
- **部門を増やす・変える**：「◯◯の部門を作りたい」と言えば司令塔が増設します。
- **面倒を減らす**：「これ毎回面倒」と言えば、手を動かさずに済む仕組みを提案します（`framework/07_道具を作ってつなぐ.md`）。

## フォルダ構成

| フォルダ | 中身 |
|---------|------|
| `CLAUDE.md` | 起動ファイル（Claudeが最初に読む短い入口） |
| `framework/` | 司令塔のエンジン（役割・統合ロジック・日次報告・モデルの使い分け・設計パターン・会話ログからの学習・道具の作り方・各種テンプレート） |
| `setup/` | セットアップの台本と、情報の預かり方の決まり |
| `examples/` | 部門の指示書の実例3つ |
| `integrations/` | 外部連携ガイド（Obsidian・Googleカレンダー・Notion・Claude in Chrome・LINE通知） |
| `dashboard/` | エージェントの活動と日次報告を眺めるブラウザ画面（任意） |
| `scripts/` | 日次報告・LINE通知・会話ログからの学習のスクリプトと、自動起動の登録 |
| `agents/` `shared/` `my-hub/` `reports/` | **あなたの**部門・データ・設定・レポートが入る場所（セットアップで生成） |

## あなたの情報について

このキットは、**あなたが自分の情報を共有するほど便利になります。** 名前・年齢・住んでいる地域・職場や学校・これまでの経験（履歴書）・普段使っているサービスを最初に聞き、文章例や健康の記録は、使い始めてから「こんなのも共有すると便利ですよ」とお勧めします。

**進めるのはゆっくりで大丈夫です。** 今日ぜんぶ揃える必要はなく、渡したくないものは渡さなくてかまいません。あとからいつでも足せます。

共有する前に知っておいてほしいこと：

- **送り先**：話した内容とファイルの中身は、処理のために Claude（Anthropic）に送られます。学習に使われるか・どれだけ保存されるかは、契約しているプランと設定で変わります。自分のプランのプライバシー設定を確かめてください。LINE通知を使う場合は、日次報告の中身がLINEも通ります。
- **置き場所**：このフォルダの中に、暗号化されない普通のファイルとして残ります（`agents/` `shared/` `my-hub/` `reports/` と設定ファイル）。会話ログからの学習を使う場合は、あなたの発言の抜き書きが `dashboard/learner/` に残ります。
- **外に出る経路**：これらは `.gitignore` によりコミット対象外で、GitHub には載りません。ただし、フォルダごと人に渡す・クラウド同期に入れる・画面を共有する、といった場合は一緒に出ます。**リポジトリを公開する前に、必ず `git status` で個人ファイルが含まれていないことを確認**してください。
- **渡さないもの**：パスワード、カード番号、口座番号、マイナンバーなどは渡さないでください。司令塔からも求めません。
- **確認と削除**：「何を預かっている？」と聞けば一覧が返り、「これを消して」と言えば消します。

## 困ったとき

- セットアップをやり直したい → `hub.config.json` を削除して `claude` を起動し直す
- 連携を後から追加したい → 「`integrations/◯◯.md` の設定をやりたい」とClaudeに言う
- ダッシュボードを入れたい → 「ダッシュボードを設定して」とClaudeに言う（`dashboard/README.md`）
- 日次報告を始めたい・止めたい → 「日次報告を設定して」「日次報告を止めて」とClaudeに言う（`framework/03_日次報告.md`）
- 覚えたことを確かめたい・取り消したい → 「何を覚えた？」「◯番は覚えなくていい」とClaudeに言う（`framework/06_会話ログからの学習.md`）
