# agent-hub starter — あなた専用のAI司令塔を作るキット

生活・仕事のあらゆる領域（タスク・お金・健康・学業・案件・情報収集…）を、**あなたが決めた「部門」ごとに専門AIエージェントへ任せ、1体の司令塔がそれらを統括する**仕組みを、あなたのPCに作るためのスターターキットです。

- どんな部門を作り、何を任せるかは**あなた次第**。セットアップ時にClaudeがインタビューして、あなた専用の構成を組み立てます。
- 毎朝、全部門が自分の担当を確かめて、知らせることがある部門だけがダッシュボードに短く報告します（日次報告・任意）。
- Obsidian・Googleカレンダー・Notion・ブラウザ操作・活動ダッシュボードなどの連携は**すべて任意**。あとから追加できます。

## 必要なもの

- **Mac または Windows**（このキット自体はどちらでも同じように動くよう作られています。自動起動の仕組みだけOSに応じて自動で切り替わります）
- [Claude Code](https://claude.com/claude-code)（AnthropicのAIエージェント。有料プラン推奨——サブエージェントを多用します）。Windowsでは PowerShell またはコマンドプロンプトからそのまま使えます（追加の仮想環境は不要）。
- **Python 3**（ダッシュボードや自動同期の実行に使う）。Windowsで未インストールの場合は python.org からインストールし、インストーラーで「Add python.exe to PATH」に必ずチェックを入れてください。

## はじめかた（3ステップ）

1. **このリポジトリを手に入れる**
   - ターミナルを開いて（Macなら Launchpad →「ターミナル」、Windowsなら PowerShell を検索）：
     ```bash
     git clone （このリポジトリのURL） agent-hub
     cd agent-hub
     ```
   - gitが分からなければ、GitHubの「Code > Download ZIP」でダウンロードして解凍し、そのフォルダでターミナル/PowerShellを開いてもOK。
2. **Claude Code を起動する**
   ```bash
   claude
   ```
3. **「セットアップ」と入力する**
   - あとはClaudeが質問しながら、あなた専用の司令塔・部門・データ置き場を組み立てます（15〜30分）。OS判定やPythonコマンドの違い（`python3`/`python`）もClaudeが自動で吸収します。
   - 途中でやめても、次回また「セットアップ」と言えば続きから再開できます。

## セットアップ後の使い方

- **普段**：Claude Code に話しかけるだけ。「今週の予定は？」「◯◯に3000円使った」——司令塔が適切な部門エージェントに振り分けます。
- **毎朝**：日次報告を有効にしていれば、ダッシュボード（http://localhost:8765）に各部門の報告が並びます。「今日の報告は？」と聞いても読めます。
- **部門を増やす・変える**：「◯◯の部門を作りたい」と言えば司令塔が増設します。

## フォルダ構成

| フォルダ | 中身 |
|---------|------|
| `CLAUDE.md` | 司令塔のブート指示書（Claudeが最初に読む） |
| `framework/` | 司令塔のエンジン（統合ロジック・日次報告・モデル振り分け・設計パターン・各種テンプレート） |
| `setup/` | セットアップウィザードの台本と、情報の預かり方の決まり |
| `examples/` | 部門エージェントの書き方の実例3つ |
| `integrations/` | 外部連携ガイド（Obsidian・Googleカレンダー・Notion・Claude in Chrome） |
| `dashboard/` | エージェント活動と日次報告を眺めるブラウザ画面（任意） |
| `scripts/` | 日次報告を集めるスクリプトと、その自動起動の登録 |
| `agents/` `shared/` `my-hub/` `reports/` | **あなたの**部門・データ・設定・レポートが入る場所（セットアップで生成） |

## 設計思想（なぜこの形か）

- **司令塔は自分で作業しない。** 発令と統合だけを担い、専門作業はサブエージェントに任せる。だから部門をいくら増やしても司令塔は太らない。
- **報告を並べるだけにしない。** 複数部門の報告から重複を束ね・横断テーマを抽出し・因果を繋ぎ・優先度を再評価する「統合ロジック」が司令塔の中核価値（`framework/02`）。
- **1ファイル1書き込み担当。** データの所有権を明確にして事故を防ぐ。
- **作業の重さでモデルを使い分ける。** 機械的な集計は軽いモデル、納品物の生成は最高性能モデル（`framework/04`）。コストにメリハリをつける。
- **読んでいない報告は採用しない。** 委任文には必ず「まず自分の指示書を読む」行を入れ、報告には実際に読んだファイルの一覧を付けさせる。一覧のない報告は差し戻す。
- **報告は事実まで。** 日次報告は「何が・いつから・どれだけ」を伝えるもので、いつ何をするかはあなたが決める。

## あなたの情報について

このキットは、**あなたが自分の情報を共有するほど便利になります。** 名前・年齢・住んでいる地域・職場や学校・これまでの経験（履歴書）・普段使っているサービスを最初に聞き、文章例や健康の記録は、使い始めてから「こんなのも共有すると便利ですよ」とお勧めします。

**進めるのはゆっくりで大丈夫です。** 今日ぜんぶ揃える必要はなく、渡したくないものは渡さなくて構いません。あとからいつでも足せます。

共有する前に知っておいてほしいこと：

- **送り先**：話した内容とファイルの中身は、処理のために Claude（Anthropic）に送られます。学習に使われるか・どれだけ保存されるかは、契約しているプランと設定で変わります。自分のプランのプライバシー設定を確かめてください。
- **置き場所**：このフォルダの中に、暗号化されない普通のファイルとして残ります（`agents/` `shared/` `my-hub/` `reports/` と設定ファイル）。
- **外に出る経路**：これらは `.gitignore` によりコミット対象外で、GitHub には載りません。ただし、フォルダごと人に渡す・クラウド同期に入れる・画面を共有する、といった場合は一緒に出ます。**リポジトリを公開する前に、必ず `git status` で個人ファイルが含まれていないことを確認**してください。
- **渡さないもの**：パスワード、カード番号、口座番号、マイナンバーなどは渡さないでください。司令塔からも求めません。
- **確認と削除**：「何を預かっている？」と聞けば一覧が返り、「これを消して」と言えば消します。

## 困ったとき

- セットアップをやり直したい → `hub.config.json` を削除して `claude` を起動し直す
- 連携を後から追加したい → 「`integrations/◯◯.md` の設定をやりたい」とClaudeに言う
- ダッシュボードを入れたい → 「ダッシュボードを設定して」とClaudeに言う（`dashboard/README.md`）
- 日次報告を始めたい・止めたい → 「日次報告を設定して」「日次報告を止めて」とClaudeに言う（`framework/03_日次報告.md`）
