# framework/03 — 日次報告（Claude manager・モードB）

司令塔がこのファイルを読むのは、オーナーが「日次報告」「今日の報告」「Claude manager」と言ったとき、または仕組みを直すとき。日常のモードAでは読まない。

---

## 何をする仕組みか

毎朝決まった時刻に、全部門から日次報告を受け取り、ダッシュボード（http://localhost:8765 のMonitor）に短く載せる。報告することが無い部門は載せない。

- 動かしているのは `scripts/claude_manager.py`。自動起動（Mac＝launchd／Windows＝タスクスケジューラ）が毎朝呼ぶ。1日1回だけ走り、今日の分がもうあれば何もしない。
- 部門ごとに `claude -p` を1本ずつ立て、`【日次報告】` を委任する（必読行つき）。**読むだけ・Web調査なし・書き込みなし。**
- 各部門は `shared/共通プロトコル_日次報告.md` の形（状態／緊急度／見出し30字／本文80字／根拠ファイル）で返す。
- スクリプトが検収する。形が崩れている報告と、根拠ファイルが実在しない報告は載せず、「届かず」として出す。
- 最後に Claude manager 役の1本（道具なし）が、重複をまとめ、緊急度を全体で付け直し、「今日の一手」を1行付ける。事実は足さない。
- 結果は `dashboard/manager/YYYY-MM-DD.json` に30日分残る（gitには載せない）。

毎朝、部門の数だけClaudeが動く。その分の使用量がかかるので、報告させる部門は絞る。

## 設定（`hub.config.json` の `daily_report`）

| 項目 | 中身 |
|------|------|
| `enabled` | 日次報告を使うか |
| `time` | 走らせる時刻（`"07:00"` の形） |
| `priorities` | オーナーの優先順位を1行で（上ほど優先）。まとめ役が並び順を決めるのに使う |
| `departments` | 報告させる部門の一覧。`num`（部門番号）・`label`（表示名）・`agent`（`agents/` のフォルダ名）・`model`（`haiku`／`sonnet`） |

参加させないもの：オーナーの依頼があって初めて成立する部門（文書・メールの作成など）と、Web調査が本体の部門。

## 司令塔が頼まれたとき

- 「今日の報告は？」→ `python3 scripts/claude_manager.py show` を読んでそのまま伝える。分析を被せない。
- 「集め直して」→ `python3 scripts/claude_manager.py run --force`（部門の数によって10分前後かかるのでバックグラウンドで）。特定の部門だけなら `--only 01,02`。
- 報告の中身を掘り下げたいと言われたら、その部門に通常どおり委任する（モードA）。

Windowsでは `python3` の代わりに `python` を使うことがある（`hub.config.json` の `environment.python_cmd`）。

## 直すとき

- 報告の書き方・報告する基準 → `shared/共通プロトコル_日次報告.md`
- 部門ごとの見る観点 → 各 `agents/XX/CLAUDE.md` の「日次報告（Claude manager）」節
- 部門を足す・外す → `hub.config.json` の `daily_report.departments` と `my-hub/司令塔設定.md` の部門表
- 時刻 → `hub.config.json` の `daily_report.time` を直し、`python3 scripts/install_daily_report.py` を流し直す
- 止める → `python3 scripts/install_daily_report.py --uninstall`
- 表示 → `dashboard/index.html` の `loadManager()`、データは `dashboard/server.py` の `/api/manager`
- ログ → `dashboard/logs/claude-manager.log`

## うまく届かないとき

- 全部門が「届かず」で、理由が「ログインが切れている」→ ターミナルで `claude` を開いて `/login` する。自動起動はターミナルと同じログインを使う。
- 「根拠ファイルが確認できない」→ その部門がデータを読めていない。`agents/XX/CLAUDE.md` のデータソースのパスが実在するか確かめる。
- Windowsで、その時刻にPCの電源が入っていなかった日は走らない。「集め直して」で取り直す。

## やってはいけないこと

> ❌ 司令塔が各エージェントのデータファイルを直接読み、日次報告を代筆すること。
> ❌ 日次報告の呼び出しの中で、記帳・取り込み・台帳の更新などの書き込みをさせること。
