# 共通プロトコル：日次報告の書き方（Claude manager）

<!-- セットアップ時に shared/共通プロトコル_日次報告.md としてコピーされる（日次報告を使う構成のみ） -->

【日次報告】で呼び出されたとき。毎朝、全部門へ同じ指示が飛び、報告はダッシュボードに短く載る。

## やること

- 自分の `CLAUDE.md` の「日次報告」節とデータソースに従い、担当データを**読むだけ**で確かめる。
- **何も書き換えない**。取り込み・記帳・台帳の更新・ファイルの作成は、起動時の決まりごとであってもこの呼び出しではやらない（取り込み待ちがあるなら、それ自体を報告する）。
- **Web調査はしない**（WebSearch・WebFetch・ブラウザは使えない）。手元の記録だけで判断する。

## 報告するかどうか

次のどれかに当てはまるときだけ「報告あり」。当てはまらなければ「報告なし」で終える。

- 期限切れ、または3日以内に期限が来るものがある
- 数字が急に悪くなった・良くなった（前の記録と比べて）
- 記録や取り込みが止まっている・漏れている
- オーナーが今日〜今週のうちに決める・動く必要がある
- 自分の `CLAUDE.md` の「日次報告」節に、数字で決めてある観点に当たった（例：「1回で2万円以上の支出」「直近3日がどれも6時間未満」）。決めてある線を越えていたら、上の4つに当てはまるか迷わず報告する

順調・変化なし・いつもどおりは報告しない。無理に話題を作らない。

## 書かないこと

- **オーナーが決めることに、期限や段取りを付けない。** いつやるか・何から手を付けるかはオーナーが決める。「今週中に1つ決める」のような指図はしない。書くのは事実（何が・いつから・どれだけ）まで。
- **やることを無理にひねり出さない。** やっても何も進まない手順を作らない。外から決まっている手続き（提出・支払い・申請など）があるときだけ、その手続きを書く。無ければ事実だけで終える。
- **オーナーの活動が空いているとき（練習・投稿・学習など）は、事実だけを書く。** 最後はいつで、何日空いているか、まで。「次はいつ」「まず何を」は付けない。緊急度は🟢にする。
- **補足欄の「本人が確認済みの印を付けた報告」と同じ件は、もう出さない。** 🔴でも出さない。出してよいのは、新しい期限・新しい出来事・数字の新しい悪化があったときだけ。日数が延びただけ・同じ数字の言い直しは新しい事実ではない。ほかに報告することが無ければ「報告なし」。
- **オーナーがもう手を打てないことは報告しない。** 知らせても取り戻せないこと（保存せずに閉じた作業など）は書かない。

補足欄の「昨日この部門が出した報告」と同じ内容は繰り返さない。ただし🔴がまだ片づいていないとき、期限が近づいて状況が進んだときは、今日の数字でもう一度出す。

## 形（この形だけを返す。前置き・挨拶・表は付けない）

報告があるとき：

```
状態: 報告あり
緊急度: 🔴 | 🟡 | 🟢
見出し: 30字以内。何が起きているかを言い切る
本文: 80字以内。数字と期限の事実。外から決まっている手続きがあるときだけ、それを1つ添える
根拠ファイル:
- 実際にReadしたファイルのパス
```

報告がないとき：

```
状態: 報告なし
根拠ファイル:
- 実際にReadしたファイルのパス
```

- 緊急度は 🔴今日中／🟡今週中／🟢今月中 のどれか1つ。
- 1部門1件。複数あるなら一番重いものを出す。
- 見出しと本文は1行ずつ。改行しない。4桁以上の数字はカンマ区切り。
- データが読めなかったら、でっち上げず `状態: 報告あり`・🔴・見出し「データが読めない」で、読めなかったパスを本文に書く。
