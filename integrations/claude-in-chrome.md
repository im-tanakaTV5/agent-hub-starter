# 連携ガイド：Claude in Chrome（ブラウザ操作の代行）

## 何ができるようになるか

- 司令塔がChromeを直接操作して、調査・ポータル確認・情報の読み取り・スクショ取得などを代行できる。
- 「ブラウザで完結できる作業は本人に丸投げせず司令塔が率先して終わらせる」運用が組める。

## 手順

1. **Chrome拡張機能をインストール**する（導入者がブラウザで実施）：
   Chrome ウェブストアで「Claude in Chrome」を検索してインストールし、Claudeアカウントでログインする。
   ※ 利用可能なプラン・地域はAnthropicの案内に従う。
2. Claude Code / Claude Desktop 側でChrome連携が有効になっていることを確認する（拡張側の接続状態を見る）。
3. `hub.config.json` の `integrations.claude_in_chrome` を `true` にする。

## 運用ルール（framework/01 と同じ。重要）

- **率先してやる（確認不要）**：調査・リサーチ、ポータルの確認、ページ内容の読み取り、スクショ取得。
- **事前に一言確認する**：提出ボタン押下・フォーム送信、個人情報の入力、投稿・共有設定の変更（不可逆・外部送信のもの）。
- 操作許可ドメインは限定されており、一部サイトはブロックされる。代行できない場合は正直に伝えて手順を案内する。**操作結果の捏造は禁止。**

## つまずきやすい点

- 拡張を入れたのに操作できない → 拡張アイコンから接続状態を確認。対象サイトが許可ドメイン外の可能性もある。
- サブエージェントは対話的なChrome操作を完結しづらいため、Chrome操作は司令塔が直接担う設計にしてある。
