# 連携ガイド：Notion

## 何ができるようになるか

- 既にNotionでデータベース（読書記録・案件リスト・日記など）を管理している場合、エージェントがそれを読み書きできる。
- 「データはNotionに置いたまま、分析・提案だけエージェントに任せる」構成が組める。

## 手順（Claude Code のコネクタ機能を使う）

1. Claude Code で Notion の MCP コネクタを追加する（Claudeが実行を案内する）：
   ```bash
   claude mcp add --transport http notion https://mcp.notion.com/mcp
   ```
   ※ claude.ai / Claude Desktop を併用している場合は、設定画面の「コネクタ」から Notion を接続する方法もある。
2. 初回接続時にブラウザが開くので、**導入者がNotionにログインして接続を許可**し、エージェントに見せてよいページ・データベースを選ぶ。
3. `hub.config.json` の `integrations.notion` を `true` にする。
4. Notionを使う部門のCLAUDE.mdのデータソース表に「Notion：（データベース名）（読み取り/読み書き）」を記載する。

## 運用ルール

- **アクセス許可は最小限に。** エージェントに関係あるページだけ共有する（Notion側の接続設定で選べる）。
- データ所有権ルールはNotionにも適用する：1つのデータベースに書き込むエージェントは1体だけ。
- Notion由来の数値も、レポートでは「Notion（データベース名）・取得日」を出典として扱う。

## つまずきやすい点

- 接続したのにページが見えない → Notion側で該当ページが接続に共有されているか確認（ページ右上「…」> 接続）。
- Claude Code のセッションを跨ぐと再認証を求められることがある。その場合は再度接続を許可すればよい。
